# 更新与回滚

自动任务按配置周期检查来源，只保存更新提示，不安装、不切换 Workspace。也可在已安装详情或更新页手动检查。来源离线不影响本地 Skill 使用。

流程：选择明确 release/commit → 下载校验 → 保存新快照 → 审阅说明、文件与脚本 → 切换目标 Workspace。回滚选择旧的已安装版本。安装、启用、停用与切换的审计包含操作者、时间、来源、digest 和新旧安装 ID。

进行中的 Run 保留旧安装引用；工作区停用会阻止后续调用。Git 检查比较仓库默认分支最新提交，只作为提示，安装仍需明确 commit。MCP Registry 版本只是观察信息，不把远端行为承诺为完全可重现。

旧快照目前只保留，不自动清理。后续空间清理必须先检查运行和历史引用，不能按当前绑定指针删除旧目录。
