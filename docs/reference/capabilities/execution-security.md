# 执行与故障边界

Workspace 来自可信 Session、Identity 与 Channel，模型不能指定任意宿主路径。资源与 MCP 都使用 ToolRuntime 用户权限和工作区检查，列表可见不代表调用已放行。

Skill 是不可信说明与只读内容，不授予新工具权。解包不运行安装脚本。现有 Python/Docker 执行边界保持独立，MCP 不会把它改造成通用宿主 Shell。

HTTP 限制协议、凭据、DNS、私网、重定向、体积与时间，连接固定到已校验 DNS 结果。HTTPS 不降级，凭据不跨来源跟随重定向，私网需要管理员精确批准。

Secrets 使用环境变量引用，不写入快照、日志、Prompt 或 WebUI 返回值。错误保留稳定状态，不保存完整临时 URL、Cookie、平台下载响应或文件字节。工具文本与结构化输出有独立预算。

外部结果未知时先核对平台。重启只收敛既有事实，不自动重放上传、删除或非幂等 MCP 调用；纯文件获取与外部写操作分别处理。
